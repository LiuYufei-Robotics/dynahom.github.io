DynaHOM: An Object-Centric Reinforcement Learning Framework for Dynamic Object Manipulation

Anonymous Authors

Overview Demonstrations Paper · Coming soon Code · Coming soon

Abstract

Dynamic object manipulation requires a robot to intercept a moving target, establish a stable grasp, and control the object's subsequent motion toward a task goal. Object shape and hand mechanism affect both grasp acquisition and the ability to retain the object during transport and reorientation. We present DynaHOM, an object-centric reinforcement learning framework for dynamic object manipulation that connects grasping, planning, and execution through object states and goals. A language-conditioned perception front end identifies the target and continuously estimates its 6D pose. An RL policy then performs dynamic grasping using object-centric feedback. Once the object is grasped, a vision-language model generates an object-level target trajectory conditioned on the task instruction. The RL policy subsequently tracks this trajectory through closed-loop control. We instantiate the framework on Unitree G1-D with a three-finger hand and on a Franka Emika Panda arm with a parallel-jaw gripper. Policies are trained separately with reward terms and control interfaces adapted to each embodiment. We validate the framework in real-world scenarios spanning dynamic object manipulation in everyday settings and conveyor-belt parcel sorting for industrial logistics.
