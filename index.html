Abstract

Dynamic object manipulation requires a robot to intercept a moving target, establish a stable grasp, and control the object’s subsequent motion toward a task goal. DynaMimic explores object-centric reinforcement learning to connect dynamic grasping and subsequent manipulation through object states and goals. The framework combines visual object-state estimation with closed-loop policy control, with applications to everyday object manipulation and conveyor-belt parcel sorting.
