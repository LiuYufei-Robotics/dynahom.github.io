DynaHOM An Object-Centric Reinforcement Learning Framework for Dynamic Object Manipulation

Overview Real World Demonstrations

Abstract

Dynamic object manipulation requires coordinated interception, grasp retention, and control of subsequent object motion. However, variations in object geometry and hand mechanisms complicate both grasp acquisition and the transport and reorientation of the grasped object. We present DynaHOM, an object-centric reinforcement learning (RL) framework for dynamic object manipulation. Object geometry, motion, and goals provide a common interface for grasping, planning, and execution. A language-conditioned perception front end identifies the target and continuously estimates its 6D pose, providing object-state feedback for RL-based dynamic grasping. After grasp acquisition, a vision-language model (VLM) generates object-space waypoints from the task instruction, and the RL policy tracks these waypoints through closed-loop control. We instantiate DynaHOM on Unitree G1-D with three-fingered hands and on a Franka Emika Panda arm with a parallel-jaw gripper, training separate policies with rewards and control interfaces adapted to each embodiment. We evaluate dynamic grasping and subsequent manipulation in simulation and real-world tasks, including everyday object handling and conveyor-belt parcel placement.
